# План DevOps проекта MTC ENGINEER HACK

Пока в репозитории находится план; решение еще не реализовано.

Идея решения — **Self-Verifying Kubernetes Stack**: единый `make verify` подтверждает HTTP, метрики, логи и security-инварианты. В final добавляется canary с автоматическим возвратом трафика на stable при неуспешной проверке. Идеи из `hackathon_features.md` включены в план и карточки сессий.

- [Архитектура и два этапа реализации](docs/implementation-plan.md) — обязательный MVP, улучшения final, заимствования из петпроектов, критерии готовности и сдача.
- [Карточки агентных сессий](docs/agent-sessions.md) — зависимости, владельцы файлов, проверки и готовые промпты для последовательной и параллельной работы.

Основной стенд: отдельная Ubuntu 24.04 VM в homelab с kubeadm. Работа начинается с MVP-00; общие контракты закрепляются до запуска компонентных агентов.
