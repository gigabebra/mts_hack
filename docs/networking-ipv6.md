# Исторический IPv6-only режим

Пользователь заменил это требование на полноценный dual-stack Kubernetes с IPv6
основным и доступным IPv4. Актуальные инструкции: [сеть MVP](networking.md),
[контракт v3](contracts.md). Строгие запреты IPv4 и прежние рекомендации по
изоляции loopback не относятся к текущей установке.

Предыдущие результаты не являются приемкой dual-stack. Старые VM и сырые evidence
сохранены отдельно; история кода доступна в Git.
