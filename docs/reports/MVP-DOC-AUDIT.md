# MVP — аудит документации после dual-stack приемки

Дата: 2026-10-01. База чтения: `ac3abaf36c704a1fc3d08ae395dc7e439a14338d`.
Документационный агент работал в отдельной ветке `audit-docs`, без SSH,
kubectl, доступа к credentials и изменений VM. Это статическая сверка
документов с кодом; новый живой прогон выполняет интегратор отдельно.
Первоначальная чистая dual-stack приемка остается привязана к `cc3afc6`.

## Область проверки

Прочитаны все 28 Markdown-файлов, существовавших на базовой ревизии:
корневые README/AGENTS, план, карточки, контракт, статус, оба сетевых
документа, четыре README инфраструктуры/компонентов, все 13 отчетов,
два протокола приемки и паспорт. Все четыре JSON в `docs/acceptance/`
разобраны; исторические сводки и их исходные результаты не изменялись.

Установка и CLI сопоставлены с Makefile, bootstrap/deploy/verify/evidence,
компонентными checkers, environment example, версиями/image lock и
конфигурациями Ansible/Helm/Nginx/Fluentd/Loki/Prometheus. Проектные
требования FINAL отделены от действующего интерфейса MVP. Соседние
репозитории и документы пользователя повторно не читались: их ссылки
в исходном плане обозначают исторические источники, а не зависимости.

Выполненные локальные команды:

```sh
python3 .state/doc-audit/check_docs.py
python3 scripts/check-gateway.py --help
python3 scripts/check-metrics.py --help
python3 scripts/check-logs.py --help
git diff --check
```

Локальный audit helper перебирает `git ls-files '*.md'`, разрешает ссылки
относительно документа, проверяет существование ссылок на код, запускает
`bash -n` для завершенных shell-блоков, читает argparse и JSON. Он не
выполняет команды развертывания из примеров. Результаты и HTTP HEAD
сохранены в ignored `.state/doc-audit/` соответствующего worktree;
в репозиторий входят только исправленные документы и этот отчет.

Проверка публичных URL подтверждает доступность страницы, а не неизменность
ее содержания или совместимость другой версии компонента. Исторические
команды воспроизводят свою указанную ревизию; текущая установка использует
корневой README, [контракт](../contracts.md) и [сеть](../networking.md).
